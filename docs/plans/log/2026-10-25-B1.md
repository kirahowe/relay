# B1: research reports and tool vetting deleted

Removed `relay.reports`, `relay.vet`, the verifier and its `:verifier`
setting, the `:reports` grant, `report_submit`, `reports`, `ledger` and
`ledger_status`, `relay verify`, `relay review`, `relay ledger` and
`relay trust-level`, the corpus scenarios of `bb pentest`, the research
eval scenario, and the stand-in verifier. The report line is gone from
the morning brief, `relay status` and `relay week`.

`relay connect` still signs in with OAuth and writes the connection file,
but it no longer asks the operator to pick a class or turn tools on and
off. It writes each tool as relay proposes it (read when the server says
read-only, otherwise act, default labels, off when the name says it
deletes) and asks for the typed code once. Class, labels and consent stay
editable in the file. B2 removes the gating they feed.

Old logs: the nine event kinds those features wrote
(`core/removed-event-kinds`) fold to nothing, keep counting their labels as
seen, and are exempt from the public-item check. `removed_events_test.clj`
folds generated logs with those events interleaved and compares them with
the same logs without them (I8).

Kept for B2: `relay.review` (consent review text for holds and trust),
`relay.text/lookalike-findings` (used by it), and `propose-class`.

The pentest web scenario (s15) still needs a hostile page and a local
server, so its helpers moved into `scenarios/web.clj`, and `pentest/corpus`
keeps the two pages it serves.
