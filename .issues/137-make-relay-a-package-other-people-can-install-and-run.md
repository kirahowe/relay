# Make relay a package other people can install and run

## Context

Kira, 2026-11-15, after the push of relay#93's first parts: "I'd like to
think about how to make this a generically useful package for more than
just me, but I think that's probably it's whole own separate epic. for
now isntalled from head is fine."

Today relay installs only from the head of `main` through Kira's tap
(`kirahowe/tap`), with no versions or releases. Issues already filed
that belong here: relay#115 (short-lived grants instead of long-lived
secrets) and relay#116 (the threat model for relay as something other
people install). Versioned releases came up in the same conversation
and were left for this epic.
