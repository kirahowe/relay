# Let Kira put a surface back as it was

## Context

Sent by the relay-macos session on 2026-11-14, through the coordinating
session. The text is that session's own, and "I" below is that session.

Part of relay#93. A role can change a surface it built, and the wake
that changes it may have read outside text. The log keeps every version
of a card. As far as I can tell from the card ops in the README, Kira
can archive a card but cannot return it to an earlier version.

The daily note lists each change to a routine or a skill that outside
text shaped, with a one-line undo. It does not list a surface that
outside text shaped.

Kira agreed to this in the relay-macos session on 2026-11-14, as one of
the five points named in relay#111.

## Acceptance criteria

A first draft, for whoever builds this to tighten.

- [ ] Kira can put a surface back to an earlier version, from the
  command line and from a client, and every client redraws.
- [ ] The daily note lists a surface that a wake which read outside text
  added or changed, with what it drew on and a one-line undo.
- [ ] README, spec/relay.allium and docs/client-protocol.md describe it.
