# Keep a ledger of findings

## Context

Findings need a home that outlives a single report so reports can show only what is new.

## Acceptance criteria

- [ ] Postings have a status: new, seen, applied or passed.
- [ ] Reports show only what is new.
- [ ] The hub can act on trusted entries without becoming contaminated.
- [ ] Whether the ledger lives in the notes store or its own file is undecided; record the choice.
